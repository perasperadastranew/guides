# Исходники методичек Mission to UX/UI

Здесь лежит всё, из чего собирается страница методичек. Править нужно только эти файлы.
`index.html` в корне репозитория собирается автоматически, руками его не трогаем.

## Где что лежит

| Что | Где |
|---|---|
| Тексты уроков | `lessons/<id>.json` — один файл на урок |
| Порядок уроков, модули, названия | `meta.json` |
| Скриншоты приложений | `../img/` и список в `img_manifest.json` |
| Иллюстрации Hairline | `figs/` и `figmeta.json` |
| Вёрстка и стили | `app.js`, `base.css`, `extra.css` |

Id уроков: s0–s5 подготовка, r1–r8 исследования, p1–p5 проектирование, g1–g3 гайдлайны,
v1–v6 визуальный дизайн, d1–d2, t1, c1–c3.

## Как поправить урок

1. Открой `lessons/<id>.json` на github.com и нажми карандаш (или поправь у себя и сделай Push в GitHub Desktop).
2. Меняй только текст внутри кавычек. Кавычки, запятые и скобки не трогай. Кавычки-«ёлочки» в тексте можно.
3. Нажми **Commit changes**.
4. Через пару минут во вкладке **Actions** появится зелёная галочка «Сборка методичек UX/UI».
   Ещё через минуту изменения видны на сайте и в ZenClass.

Если галочка красная, значит в файле ошибка (чаще всего лишняя или пропущенная запятая или кавычка).
Открой запуск в Actions: там написано, в каком уроке ошибка. Исправь и сохрани ещё раз — сайт при ошибке не меняется.

## Проверить у себя (необязательно)

```
python3 uxui-metodichki/src/build.py
```
