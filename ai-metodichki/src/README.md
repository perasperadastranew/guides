# Исходники методичек Mission to AI

Страница для студентов: https://perasperadastranew.github.io/guides/ai-metodichki/
Ссылка на конкретный урок: в конце адреса `#/<id урока>`, например `…/ai-metodichki/#/l2_2`.

Здесь лежит всё, из чего собирается страница. Править нужно только эти файлы.
`ai-metodichki/index.html` собирается автоматически, руками его не трогаем.

## Где что лежит

| Что | Где |
|---|---|
| Тексты уроков | `src/lessons/<id>.json`, один файл на урок |
| Порядок уроков, модули, названия в оглавлении | `src/meta.json` |
| Картинки (слайды лекций и кейсы студентов) | `img/`, формат `.webp` |
| Вёрстка и стили | `src/app.js`, `src/base.css`, `src/extra.css`, `src/ai.css` |

## Как поправить урок

1. Найди файл урока в таблице ниже, открой его на github.com и нажми карандаш.
2. Меняй только текст внутри кавычек. Кавычки, запятые и скобки не трогай. Кавычки-«ёлочки» в тексте можно.
   Выделить жирным: `<b>текст</b>`. Перенос внутри промпта: `\n`.
3. Нажми **Commit changes**.
4. Через пару минут во вкладке **Actions** появится зелёная галочка «Сборка методичек Mission to AI».
   Ещё через минуту изменения видны на сайте и в ZenClass.

Если галочка красная, значит в файле ошибка (чаще всего лишняя или пропущенная запятая или кавычка).
Открой запуск в Actions: там написано, в каком уроке ошибка. Исправь и сохрани ещё раз. Пока ошибка не исправлена, на сайте остаётся прошлая версия.

## Как добавить картинку

1. Сожми картинку в `.webp` шириной до 1400 px и загрузи в папку `ai-metodichki/img/` (Add file → Upload files).
2. В уроке добавь её в блок `gallery`: `{"img": "имя-файла-без-webp", "tag": "пример", "title": "…", "note": "что тут важно"}`.
   Сборка проверяет, что файл с таким именем существует.

## Какие бывают блоки

Самые частые: `p` (абзац), `note` (плашка), `table`, `steps`, `pairs` (плохо / хорошо), `prompt` (промпт с кнопкой копирования),
`builder` (конструктор промпта), `gallery` (картинки), `myths`, `task`, `check`, `faq`. Тест — в поле `quiz` в конце файла,
у каждого вопроса ровно один вариант с `"ok": true`.

## Проверить у себя (необязательно)

```
python3 ai-metodichki/src/build.py
```
