# Исходники короткой версии «Как начать в AI-индустрии»

Страница `ai-start/index-short.html` собирается скриптом, руками её не правим — иначе следующая сборка затрёт правки.

- `orig.html` — база: стили, подвал, подписки, таблицы, скрипты калькулятора.
- `build.py` — структура и тексты: части I–IV, итог, графики, списки.
- `add.css`, `add.js` — новые блоки (башня по годам, перепись, мифы, 20/80, график «часы × цена», нейросети, итог).

Сборка: `python3 ai-start/src-short/build.py` → обновится `ai-start/index-short.html`.
