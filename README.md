# guides — методички PERASPERADASTRA

Сайт: https://perasperadastranew.github.io/guides/ — страницы встроены в уроки ZenClass через iframe.
**Старые папки не переносим и не переименовываем:** адрес страницы прописан в уроках, перенос сломает встраивание.

## Как добавить методичку

1. Скопируй папку `_template/` в `<курс>/<тема>/`: `mtw/` (Mission to Web), `mtm/` (Mission to Motion), `ai/` (Mission to AI), `uxui/` (Mission to UX/UI), `obshchee/` (для всех курсов). Имя — латиницей через дефис, по теме, без номера урока: `mtm/kineticheskaya-tipografika/`.
2. В `index.html` замени всё в `[квадратных скобках]`. Ненужные блоки удали, нужные копируй. Оформление и скрипты не трогай — они общие с эталоном `brending/platforma`.
3. Текст — по правилам: на «ты», простыми фразами; примеры конкретные; работы студентов — только с согласием; цен и версий сервисов не пишем.
4. Проверь у себя: `python3 tools/proverka.py --changed origin/main` (и открой страницу на ширине 390 px).
5. Отправь в ветку и открой pull request. Саша смотрит → «да» → merge в `main`, страница обновится за пару минут.
6. В ZenClass: блок HTML в начале урока, iframe со ссылкой на страницу (`?fit=1`, без внутреннего скролла) и ссылка «Открыть методичку на весь экран». Сохранить урок — после «да» Саши по превью.

## Автопроверка

При каждом изменении `.html` GitHub запускает `tools/proverka.py` (вкладка Actions, задача «Проверка методичек»).

- **Ошибка — проверка красная:** нет `<!doctype html>`, `lang="ru"`, `charset`, `viewport` или `<meta name="robots" content="noindex">`; название школы не как PERASPERADASTRA.
- **Предупреждение — жёлтая пометка, только у изменённых страниц:** обращение на «вы», цены и валюта, Readom и Grok, горизонтальный скролл на ширине 390 px. Не блокирует: «вы» в цитате или цены в калькуляторе подписок — нормально, но посмотреть надо.

## Где что

- `_template/` — шаблон новой методички.
- `tools/proverka.py` — автопроверка.
- `uxui-metodichki/src`, `ai-metodichki/src`, `mtw/lending`, `dokumenty-shkoly` — собираются скриптами в Actions: правим исходники, а не готовый `index.html`.
