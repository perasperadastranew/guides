# Wisteria Lane — 3D-улица из «Отчаянных домохозяек»

Интерактивная изометрическая улица: 13 домов, детективная игра на 15 улик, ночь, осень, сезоны сериала, разрез дома Бри. Фан-концепт, некоммерческий.

Сайт: https://perasperadastranew.github.io/guides/ai/wisteria-lane/ulica/
Гайд «как это сделано»: https://perasperadastranew.github.io/guides/ai/wisteria-lane/

## Что где лежит

| Путь | Что внутри |
|---|---|
| `src/wl_model.py` | Генератор всей улицы: дорога, дома, дворы, деревья. Один скрипт, два режима — внутри Blender и просто в Python |
| `ulica/` | Сайт на three.js: `index.html` и готовые модели в `ulica/map/` (glTF: `.json` + `.bin`) |
| `index.html`, `a/` | Гайд-лид-магнит: 11 шагов с промптами и картинками |

## Как открыть локально

Сайту нужен локальный сервер (модели грузятся через fetch, с `file://` не откроется). Из папки `ai/wisteria-lane`:

```bash
python3 -m http.server 8000
```

Гайд — http://localhost:8000/, сайт — http://localhost:8000/ulica/.

Клавиши: ← → — соседний дом, N — ночь, O — осень, D — режим рисунка, E — блокнот улик.

## Как пересобрать модели

Без Blender, только Python 3 (внешних библиотек не нужно):

```bash
cd src
python3 wl_model.py ../ulica/map
```

Скрипт перезапишет `ulica/map/*`: дома, землю, растительность (`kit.json` + `scatter.json`) и интерьер дома 4354.

В Blender: вкладка Scripting → открыть `wl_model.py` → Run Script. Скрипт соберёт каждый дом отдельной коллекцией, сцену улицы и сохранит рядом `wisteria_lane.blend` и `wisteria_lane.glb`.

### Что менять в генераторе

- `CTRL`, `ROAD_W`, `SET_Z` — план улицы и ширина дороги.
- Классы `Mesh` и `House` — примитивы (`box`, `gable`, `gambrel`, `hip`…) и детали дома (`window`, `door`, `bay_window`, `porch`, `yard`).
- Функции `house_43xx()` — каждый дом отдельно.
- `INTERIORS` / `INTERIOR_ROOMS` — разрез дома Бри.

## Как устроен сайт

Всё в одном `ulica/index.html`, без сборки. three.js r128 и GLTFLoader подключены с CDN.

- Камера ортографическая, двигается по скроллу: одна секция страницы — один дом. Клик по дому или вкладке — камера перелетает прямо к нему.
- Свет, туман, AO, осень, ночные окна, сайдинг, черепица и кирпич дописаны в шейдеры функцией `patch()`. Текстур-картинок нет.
- Пост-обработка своя: MSAA, тилт-шифт, свечение ночью, грейдинг, режим рисунка.
- Губернатор производительности сам снижает качество на слабых устройствах.

## Публикация

На GitHub Pages сайт работает как есть. В опубликованной версии отладочный `window.__wl` выключен. Если хостинг не отдаёт `.bin` (так было с артефактами Claude), переименуйте буферы в `.wasm` и поправьте ссылки `uri` в `ulica/map/*.json`.
